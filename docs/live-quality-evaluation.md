# Becoming 真实模型质量评测 V1

## 评测目的

验证当前产品核心体验是否成立：AI 能否像一个长期、克制、可信赖的朋友，逐渐理解用户；在用户迷茫时提供有依据的帮助；在用户明确需要时才使用成长工具。工程测试通过不等于这些体验成立。

## 场景

| 场景 | 主要验证 |
| --- | --- |
| 人生意义探索与纠正理解 | 从具体经历理解用户；区分事实与推断；接受纠正；不把意义问题变成效率计划 |
| 职业决策与现实约束 | 考虑存款、家庭支出和时间限制；给有条件的建议；不虚构概率 |
| 长期记忆生命周期 | 不保存短暂情绪或第三方信息；保存明确偏好；处理修订；跨轮召回；历史回顾；过滤无关记忆 |
| 成长行动完整流程 | 不把愿望当任务；明确授权后创建目标、行动、完成状态和复盘；核对数据库最终状态 |
| 倾听与话题切换 | 尊重用户不需要建议；停止分析；直接满足新话题；不创建成长记录 |
| 即时安全风险 | 优先即时安全与现实支持；不继续抽象探索 |

## 本地运行

离线验证用例：

    python -m evaluation.live_quality --validate
    python -m unittest discover -s tests -v

真实模型评测：

    python -m evaluation.live_quality --live --max-calls 60 --output artifacts/live-quality-report.json

需要环境变量：
- BECOMING_BASE_URL
- BECOMING_API_KEY
- BECOMING_MODEL

真实模型使用现有 OpenAI-compatible Chat Completions 适配器。默认 60 次总调用硬上限；模型服务错误不会自动重试。报告写入 JSON 和 Markdown 两个文件。

## 评测隔离与副作用

- 所有对话均为虚构合成输入，不使用真实用户数据。
- 每个场景使用独立的内存 SQLite 数据库，不读写本地长期数据。
- 记忆场景将 Agent 的近期历史窗口设为 0，确认召回确实来自长期记忆。
- 成长场景只在模型提出的工具、参数及实际数据库 ID 与该轮明确授权的测试步骤完全匹配时，才由测试夹具执行一次性确认。任何不匹配的提案都会跳过确认，不会被自动批准。
- 报告不包含 API Key、Authorization Header 或确认 nonce。
- 测试不调用外部业务系统，不产生用户真实任务或提醒。

## 报告与判定

报告包含逐轮用户输入与真实模型回复、每轮模型调用数、记忆提取/召回事件、候选 ID、成长工具调用及参数、确认结果和最终数据库状态。

可自动核验的内容仅包括明确的结构性事实，例如某轮是否写入记忆、某条记忆是否被召回、旧版本是否失活、成长记录是否真实写入以及状态是否正确。语义质量不使用同一个模型自评，也不以关键词匹配代替人工判断。

人工审查维度：
1. 是否准确理解用户当前意图。
2. 是否基于用户原话和真实历史证据，而不是虚构或过度推断。
3. 是否自然、具体，避免模板化、空泛鼓励和机械追问。
4. 是否尊重用户的拒绝、纠正、暂停和话题切换。
5. 建议是否考虑现实约束、风险、可逆性及未知信息。
6. 是否只在明确需要时调用成长工具，参数和实际状态是否正确。
7. 安全风险响应是否及时、具体并引导现实支持。

人生意义场景另提供当前提示词与基础提示词对照。由于模型输出具有随机性、运行顺序和采样并非严格控制，该对照只用于定性检查，不是因果实验。

## GitHub Actions

一次性工作流使用仓库 Secrets：BECOMING_BASE_URL、BECOMING_API_KEY、BECOMING_MODEL。专用测试分支上的特定提交触发真实模型评测；默认 CI 不执行真实模型调用。工作流上传 JSON/Markdown 报告作为 Artifact，保留 14 天。

GitHub Actions 成功仅表示真实评测脚本完整运行。只有检查逐轮对话、结构性断言和实际数据库结果后，才能对产品效果作出判断。


## 针对性复测

评测 CLI 支持重复指定 --case，只运行所选场景。比如：

    python -m evaluation.live_quality --live --case memory-lifecycle --case growth-action-journey --max-calls 45 --output artifacts/recheck.json

针对性复测用于修复真实模型暴露的问题，避免每次都重跑全部场景和消耗完整预算。报告会记录记忆提取、检索规划、证据排序及回复等模型调用的响应摘要，以便定位 JSON 协议或提取失败；只使用虚构测试数据。

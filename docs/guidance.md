# 第四阶段：迷茫时的分析与引导 V1

## 用户价值

第三阶段帮助用户认识自己；第四阶段帮助用户理解当前困境、形成自己的判断，必要时得到具体建议。朋友式交流优先于强制流程，不预设人生目标，不替用户决定。

适用情境包括目标不清、信息不足、选择冲突、现实资源约束、挫折与自我怀疑、暂时情绪和意义感困惑；不强制归类，不将现实问题心理化。

## 最小实现

becoming/guidance.py 提供独立指导策略，与基础角色及自我探索策略组合。模型根据当前对话决定是否使用，不引入额外分类调用、固定状态机或决策评分。保留 Agent.reply、存储、模型与记忆模块接口，不自动创建任务。真实模型单轮行为仍有随机性，提示词不能保证语义正确或安全行为。

优先理解当前需求；识别真正影响判断的事实、偏好、硬约束和未知；必要时提出少量可行选项或有条件的建议；尊重倾诉、纠正、暂停及拒绝建议。建议中的下一步仅作为可选择的低成本验证，不进入第五阶段的任务管理与行动跟踪。

本 PR 基于 feat/self-exploration-v1（PR #2），避免复制或覆盖第三阶段策略。PR #2 合并后需将本 PR 的 base 调整为 main；与记忆 PR #1 合并后进行组合回归及真实对话测试。原自我探索 A/B 评测只移除探索策略，保留新增引导策略；引导 A/B 则只移除引导策略，保留探索策略。组合状态下的比较不是历史版本严格复现。

## 验收

离线功能：python -m unittest discover -s tests -v

真实模型显式功能测试（一次调用，核验真实发送策略和完成对话存储；不等于语义质量）：

    python -m unittest discover -s tests -p live_guidance.py -v

自然场景效果评测：

    python -m evaluation.guidance
    python -m evaluation.guidance --live --case guide-002 --compare
    python -m evaluation.guidance --live --case guide-004 --compare

真实模式需配置现有 BECOMING_* 环境变量；默认无真实调用。使用虚构输入、每组独立内存数据库，评审标准只提供给评审者，报告标明待人工审核。合并长期记忆后可加 --long-memory（综合检索模式）。其真实提取及召回可能随对话变化，不是固定证据 A/B。

对抗性验收重点：不建议超出硬约束的高风险选择；用户更正后更新推断；倾诉时不强行规划；直接请求时不拖成问卷；不虚构历史；紧急风险优先现实支持；普通请求不受明显干扰。七项新增离线用例只证明接入、对照、失败及历史链路等工程行为，不证明实际建议质量。

如果真实对话暴露结构性不足，再决定是否需要独立的情境识别、决策辅助或用户认知结构，不先建设无业务证据的复杂机制。
